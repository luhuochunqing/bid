# 评分解析页面证据与计分单元修复

**Feature Branch**: `agent/codex/scoreparse-rule-extraction`
**Created**: 2026-09-23
**Status**: Draft
**Input**: 先修评分解析的页面证据与复核覆盖，再修计分单元及校验契约；保留原文追溯和审核保护，并按真实计分规则判断。

## User Scenarios & Testing

### User Story 1 - 跨页评分表证据完整可复核 (Priority: P1)

解析续页、跨页表头或合并单元格时，每个来源格关联物理页，并把相关页图像送入视觉提取。Word 继续使用 Sidecar 结构化合并网格。

**Why this priority**: 页面/单元格证据不完整时，后续模型、规则和人工复核都无从判断。
**Independent Test**: PDF 两页续表中来源格映射到正确页且相关图像进入模型请求；Word 跨行合并仍映射正确。

**Acceptance Scenarios**:
1. **Given** PDF 评分表在第二页续行，**When** 转换提取，**Then** 每行/格保留物理页号且请求包含续页图像。
2. **Given** 图像响应因数量/字节上限截断，**When** 校验证据覆盖，**Then** 截断不能被当成完整覆盖并自动通过。
3. **Given** Word 有横向或纵向合并，**When** 转换评分网格，**Then** gridSpan/vMerge 仍可定位来源格。

### User Story 2 - 复核只在证据更强时替换初次结果 (Priority: P1)

补充复核使用与初次提取相同的相关页图像和原文证据校验。只有复核结果通过同一契约且覆盖更完整时才替换；空、降级或不完整结果不能覆盖较好的初次结果。

**Why this priority**: 当前非空即覆盖，会把有效结构结果换成证据更弱的结果。
**Independent Test**: 确定性测试初次强/复核弱及初次弱/复核强两种选择。

**Acceptance Scenarios**:
1. **Given** 初次通过来源校验而复核未通过，**When** 选择结果，**Then** 保留初次结果。
2. **Given** 初次缺证据而复核使用原页图像且完整通过，**When** 选择结果，**Then** 采用复核结果。
3. **Given** 两次结果都不完整，**When** 解析结束，**Then** REVIEW_REQUIRED 且不替换正式评分项。

### User Story 3 - 按父子关系计算真实计分单元 (Priority: P1)

显式记录父项对子项的计分关系：SUM、SHARED_CAP、BEST_OF、MUTUALLY_EXCLUSIVE、UNKNOWN。总分和正式候选只按真实计分单元计算；子项仍保留为可追溯复核事实。关系不明时人工复核。

**Why this priority**: 把所有父子关系按“父分=子项之和”处理会拒绝共享上限等有效规则；一律求和叶节点又会重复累计。
**Independent Test**: 纯领域测试五种关系下的有效单元、总分和自动发布决策。

**Acceptance Scenarios**:
1. **Given** 原文明确独立子项分别计分并累计，**When** 验证，**Then** 子项相加并校验父项/声明总分。
2. **Given** 多条件共用最高分，**When** 验证，**Then** 上限只计一次，条件保留作证据，不因父子分值不等判错。
3. **Given** 多方案择优或互斥，**When** 计算，**Then** 父分只计一次，不累计互斥子项。
4. **Given** 原文无法判明关系，**When** 验证，**Then** REVIEW_REQUIRED，不自动覆盖正式数据。
5. **Given** 历史快照无关系字段，**When** 读取，**Then** 使用兼容 SUM 语义，API 字段可选。

## Edge Cases

- 续页无重复表头，同一评分项跨页，表格起始页与来源格实际页不同。
- 图像上限导致少送页面；引用页缺图必须阻断自动通过。
- 一条规则引用多个格或跨页格；逐字引文及全部来源 ID 均保留。
- 父节点混合描述性条件与独立计分后代；按直接关系递归选有效单元。
- 声明总分对应局部章节或多组评分项；不得强行合并未知范围。
- 空父项、循环/悬空父 ID、重复来源锚点仍不得自动发布。

## Requirements

### Functional Requirements

- **FR-001**: Sidecar MUST 保留 PDF 续表每个行/格的物理页来源并兼容旧 artifact。
- **FR-002**: 后端 MUST 按来源格实际页选图，并将截断/遗漏页作为完整性状态。
- **FR-003**: 初次提取及补充复核 MUST 经相同来源校验；支持图像请求时复核 MUST 使用相同相关页图像。提供方拒绝图像请求时才可尝试原文复核，仍须逐格证明来源与总分；被截断或引用页缺失时不得自动通过。
- **FR-004**: 结果选择 MUST 比较确定性验证状态，不得只因非空覆盖初次结果。
- **FR-005**: 父子关系支持 SUM、SHARED_CAP、BEST_OF、MUTUALLY_EXCLUSIVE、UNKNOWN；API 和持久快照字段可选且稳定。
- **FR-006**: 纯领域策略按关系计算计分单元：SUM 递归累计子项；其他已知关系父项只计一次、子项保留为条件事实；UNKNOWN 禁止自动发布。
- **FR-007**: 声明总分、原文总分证明、候选项和发布门禁 MUST 共用同一计分单元策略。
- **FR-008**: 事实可引用多个来源格；所有格须在评分范围内，引文须逐字匹配，缺失/矛盾仍需复核。
- **FR-009**: 复核快照 MUST 返回持久关系及全部子项证据；旧快照按 SUM 解释，历史正式评分项不重解析、不修改。
- **FR-010**: 关系字段 MUST 有正向/回滚迁移，不重算历史得分。
- **FR-011**: 仅 AUTO_APPROVED 且原文证据完整、总分闭合的结果可沿用正式写入；REVIEW_REQUIRED 仍受审核保护。
- **FR-012**: 非 SUM 关系必须由事实引用的原始单元格文字明确支持；模型生成的 ruleText 本身不能证明关系类型。

### Key Entities

- **评分事实**：条款事实、父事实、一个或多个来源格、原文引文、验证状态及直接子项关系。
- **有效计分单元**：在关系规则下恰好参与方案总分的分值节点。
- **复核快照**：不可变解析任务事实与证据，供审核对照。

## Success Criteria

- **SC-001**: PDF 跨页案例中每个引用页均在视觉请求中且来源格可映射到物理页。
- **SC-002**: 提取/复核结果选择验证更完整一方；未通过复核不得覆盖已通过初次结果。
- **SC-003**: 四种已知关系产生唯一可解释计分结果；UNKNOWN 统一进入 REVIEW_REQUIRED。
- **SC-004**: 自动发布事实均有逐字原文和来源格；不合格事实不改变既有正式数据。
- **SC-005**: 历史无关系数据可读取，迁移回滚不删改历史事实。

## Assumptions

- 关系表示父事实与直接子事实之间的约束；声明总分 scope 沿用当前机制。
- SHARED_CAP 表示多个条件共用父项最高分；正式候选保留父项完整规则，条件留存复核快照。
- BEST_OF/MUTUALLY_EXCLUSIVE 只有原文明确才能采用，不能从数字推断。
- PDF 页码使用 Sidecar 1 起始物理页号；DOCX 不引入新的 PDF 渲染依赖。
