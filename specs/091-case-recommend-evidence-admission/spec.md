# 案例推荐证据准入

**初始基线** `d31a25335`

## 业务规则

- **FR-001** 项目 38 的评分项 739 与 750 使用同一自营 SKU 数量比较细则。现有案例缺少可核验的数量截图，接口须给出待核验状态并返回空案例列表。既往数量陈述、商品管理和仓库管理方案均不进入该项结果。
- **FR-002** 按条款是否同时要求可度量的事实、量化评分和原始材料决定准入。规则同样适用于其他数量、金额、年限和时效场景。评分类型字段、项目名与相似度单独均不足以判定。
- **FR-003** 纯证明条款在缺少可核验原件时返回待核验和空案例列表。即使条款命中业绩分类，也在查询业绩资格和历史案例前返回。普通业绩条款沿用业绩专用处理，已有企业证书匹配继续使用企业资质库。明确要求方案的复合条款可显示历史参考，并保留待核验提示和适用的业绩准入门槛。
- **FR-004** 抽屉显示服务端待核验状态，并在切换评分项时忽略上一请求。案例标题说明参考用途。旧响应缺少新字段时按历史案例参考展示。
- **FR-005** 缺少已核验资料时不得生成数量、截图时间或资格结论。首期无已接入的结构化 SKU 截图来源，该类条款进入人工核验。

- **FR-006** 评分项 ID 必须属于当前项目。不存在或不属于当前项目时返回 404，且不查询候选或资质。

## 验收

- 生产条款回归使用项目 38 的真实文本和已复现的两个评分项编号，检查方案和旧数量陈述被拒绝。
- 对照项目 1371 的纯业绩证明条款与运营复合条款。前者要求有效合同、不同季度的订单截图和对应发票，断言待核验、空结果且不查询候选或业绩资格。后者断言可返回方案参考及达标业绩，并显示待核验提示。另用财务证明、厂家授权份数和带数字的普通方案检查边界。
- 校验企业证书及配送项回归、抽屉显示和异步切换。另行记录实际环境端到端验收结果。
