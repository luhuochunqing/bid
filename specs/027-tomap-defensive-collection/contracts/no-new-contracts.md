# Contracts: 防御性 Collection 与优雅降级治理

**Date**: 2026-07-03

## 概述

本 feature 不涉及新 API 契约。纯代码治理任务，不改变任何对外接口的行为契约。

## 现有契约影响

### API 契约（不变）

| 端点 | 原行为 | 修改后行为 | 契约变更 |
|---|---|---|---|
| `GET /api/tenders` | 边界数据时 500 错误 | 边界数据时正常返回（装饰性字段可能为空） | **行为修复**（原来就是 bug） |
| 其他列表/详情端点 | 同上 | 同上 | 同上 |

### 异常响应契约（微调）

| 异常类型 | 原 HTTP 状态 | 原 body | 修改后 HTTP 状态 | 修改后 body | 契约变更 |
|---|---|---|---|---|---|
| IllegalStateException | 409 | `{"code":409,"message":"<内部细节>"}` | 409 | `{"code":409,"message":"<内部细节>"}` | 无变更（PR #1640 保留 409） |

> 注：PR #1640 已决定保留 409 状态码和 `ex.getMessage()` 以维持 API 契约。未来可考虑对外返回通用信息，但属于独立 API 治理任务。

### 内部契约（不变）

- ArchUnit 守卫规则：新增内部约束，不影响对外接口
- pre-push gate 脚本：新增内部约束，不影响对外接口
