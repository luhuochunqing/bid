# 提交 PR 前三技能审查闭环

用户于 2026-11-04 批准：ai-slop-cleaner → 测试 → google-code-review → xiyu-code-review；问题自动交回写入 Agent，最多三轮，每次修复后重新执行整条链。

## 验收条件
- AC1：pr-create、gitee-pr-helper create、pre-push、pre-push-gate 共用仓库检查器；缺失失败关闭。
- AC2：精确执行三个技能；审查是新的只读 Agent 进程，写入只允许启动时的改动文件。
- AC3：测试失败、阻断发现和未处理建议自动修复，第三轮仍失败停止；ESCALATE、越界和进程故障立即停止。
- AC4：凭证绑定分支、基线、完整内容含未跟踪文件、日志与报告；修改失效，同内容提交可复用；交付必须干净且 PR 远端 head 等于本地 HEAD。
- AC5：保留每步退出码及历史，新失败不能复用旧成功；run 不发布、不合并、不部署。
- AC6：真实临时 Git 和进程测试验证自动闭环、上限、失效及入口阻断。

## 信任边界
配置的本地适配器是受信任进程；运行记录不证明 LLM 判断一定正确，不能抵御开发者主动篡改本地脚本，也不等于 Gitee 服务端已配置保护。
