# Data model

无schema或公开DTO字段变更。ScoreParseFact保留全部源事实。内部SCHEME_QUALIFICATION沿用既有来源核验语义；ScoreParseReviewDTO针对当前fact.weight重算可计分资格，不改变原始scopeStatus。

ScoreParseFactEvidenceWriter仅对SourceDeductionSelectionPolicy.verified通过的原始零分扣分事实新增现有证据表记录：kind=SOURCE_VERIFIED_ZERO_DEDUCTION，quotedText为完整原始sourceText；不由客户端提交。Mapper与应用编排检查同factId、原始零分、IN_SCHEME来源资格及原文相等，编辑sourceText后失效。

ScoreReviewAdoptionPolicy.CandidateInput增加仅内部使用的verifiedZeroDeduction，旧构造默认false。ScoreCandidate在调整后正分或可信零分扣分时产出；ScoreItem读取不变。无标记的历史零分保持审计待重新解析核验，不按关键词补标记。
