# Feature Specification: 跨页评分来源闭合
**Branch**: agent/gemini/scoreparse-1124-source-closure
**Created**: 2026-11-17
**Status**: Approved scope from user immediate-fix request
**Input**: 立即修复上一轮已证实的重复计分、物流漏项、父子错挂及规则正文丢失。
## User Scenarios & Testing
### US1 来源唯一且完整（P1）
给定同一方案、文档和物理评分行的重复模型事实，解析只保留一个评分单元；同格不同独立子规则仍保留。跨页配送规则保留完整条件和分值，证据闭合后属于当前方案。
### US2 层级与分组闭合（P1）
多层合并单元格下，子项按来源归入正确父组；商务20/技术50/价格30可从原件闭合出100。不同方案或缺失证据不得强行凑100。
### US3 人工复核保持可读（P1）
来源唯一且完整时正文不得因重复模型条目或短摘要丢空；不确定边界仍保留复核诊断。
## Requirements
- FR001 同来源同评分单元去重幂等且输入顺序不改变有效计分。
- FR002 跨页唯一闭合来源完整绑定，不能因页码提示为印刷页而漏项。
- FR003 基于原文而非模型命名校验父子关系及总分。
- FR004 不删除同格独立子项、不跨文档/方案合并、不自动批准来源未知事实。
- FR005 私有输入不得入库；必须有合成失败/通过、相邻回归和金标回放证据。
## Success Criteria
SC001 合成对应结构无重复、漏项、错挂和空规则，叶子总分100；SC002 已有来源歧义反例全部保持拒绝；SC003 真实私有输入回放与线上部署验收分别报告。
## Scope
本地修复和验证，不自动部署、改历史生效项或触发线上重解析。
