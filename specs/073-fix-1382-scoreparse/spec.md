# Feature Specification: 评分项证据链修复与跨文件隔离

**Feature Branch**: `073-fix-1382-scoreparse`
**Created**: 2026-09-26
**Status**: Draft
**Input**: 修复项目1382招标文件评分项提取问题，并确保修复不改变其他格式文件的解析。

## User Scenarios & Testing

### User Story 1 - PDF评分结构保持正确归属 (P1)
评审人员重新解析PDF时，跨页评分表的子部分标题不能误关闭外层评分章节，真正的新章仍须隔离。

**Independent Test**: 脱敏PDF结构回放Sidecar跨页归属，目标页候选可追溯，真正跨章反例仍阻断。

**Acceptance Scenarios**:
1. Given 表格内部出现子标题且评分表跨页，When 转换PDF，Then 下一页评分行仍归属原方案，除非存在确定的新章事件。
2. Given 文档真实进入新章，When 转换PDF，Then 新章前后表格不得合并。
3. Given 标题层级证据不足，When 解析，Then 保守阻断而不扩大范围。

### User Story 2 - 评分叶子由同一原文条目证明 (P1)
评审人员查看结果时，名称、规则、类别和最大分来自同一已定位原文条目；证据不唯一时保持人工复核。

**Independent Test**: 固定候选输入经过Sidecar结构和Java绑定，断言证据范围及资格；DOCX/text对照结果不变。

**Acceptance Scenarios**:
1. Given PDF名称与规则分处同一条目不同单元格，When 绑定证据，Then 输出含文档、章节、表格、行、单元格及片段位置的唯一范围。
2. Given 同名条目跨章重复、多个规则匹配或跨页续行不连续，When 绑定，Then 不任意选取并保持待复核。
3. Given 类别标签及共享权重格，When 映射评分项，Then 类别与最大分由对应范围证明，不从相邻项借用。
4. Given 非确定权重或否定、更正、多候选，When 判定，Then 遵守既有安全策略并在歧义时复核。

### User Story 3 - 新解析状态与正式结果清晰呈现 (P2)
旧正式项仍存在时，评审人员也能看到最新任务候选和阻断原因，并区分当前生效项与最新解析状态。

**Independent Test**: 构造旧正式3项与新任务待复核状态，验证候选可见、来源时间不混淆且采纳保护有效。

## Edge Cases
- 混合PDF、DOCX调整文件顺序时，格式规则按各源文件分流。
- 未知章节、目录、跨页续行、合并单元格及共享权重格保持确定性。
- 旧正式结果与解析中、失败、过期及人工采纳状态并存。
- 其他PDF、DOCX、文本/OCR原成功和安全拒绝样本不能有无解释的资格变化。

## Requirements
### Functional Requirements
- **FR-001**: 区分PDF评分条目内部子标题与章级边界；不确定时不得跨范围自动绑定。
- **FR-002**: 名称、规则、类别、最大分绑定到可追溯的同一原文条目范围。
- **FR-003**: 同一条目的合法引文形式指向同一业务条目；多候选必须复核。
- **FR-004**: PDF规则不得因批次首文件类型应用于其他源文件；混合输入逐文档分流。
- **FR-005**: DOCX、文本/OCR及其他PDF语义由差分样本证明；不得硬编码项目、页码、名称、分值或总分。
- **FR-006**: 最新候选与当前生效评分项同时可见；最新解析状态和时间不能被误认为生效项更新时间。保留权限及任务版本保护。
- **FR-007**: 歧义、缺证、方案或总分不明时保留人工复核，不强行补分或采纳。
- **FR-008**: 不自动改写历史正式评分项；替换须经过现有发布门槛。

### Key Entities
- **源文档范围**：文件身份、格式、文档/章节/表格/行/单元格及原文片段坐标。
- **评分条目证据**：同一条目的名称、类别、规则、权重声明及来源关系。
- **解析任务视图**：当前候选、资格/阻断原因与历史正式结果来源。

## Success Criteria
- **SC-001**: 固定1382 PDF回放中13个人工标注叶子均可追溯且合计100分、类别分组与原文一致，否则失败。
- **SC-002**: 新章、未知章、歧义负例保持阻断；新AUTO_APPROVED差异须有独立原文依据。
- **SC-003**: 跨格式/多文件差分集既有成功与拒绝结果无未解释变化。
- **SC-004**: 旧正式结果与最新候选并存时，明确标出当前生效项、最新解析时间和阻断原因，不伪造生效项任务来源。
- **SC-005**: 测试环境真实重解析及浏览器验收成功；不可用时记录未完成，不宣称端到端完成。

## Assumptions
- 私有固定候选和脱敏结构可作确定性回放，不能代替真实模型回放。
- 项目1382预期只属于测试，不进入生产规则。
- 默认无数据库迁移和外部API破坏；若需要须先补充规格与兼容策略。
