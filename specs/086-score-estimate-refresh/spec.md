# Feature Specification: 全量知识库预判刷新
Created: 2026-11-12。Branch: agent/claude/score-estimate-refresh。用户四点设计已批准。
## User Scenarios & Testing
- US1(P1): 无证书但有业绩与仓储时刷新全部生效评分项，保存新结果及依据。
- US2(P1): 显示本次处理/数值得分/无分值项数与逐项原因；0分算数值；空跑不能显示完成。
- US3(P1): 招标解析区域折叠后仍可点击按钮，无生效项说明原因。
- US4(P1): 页面与保存一致，候选和实际评分逐字段不变，权限拒绝和版本冲突不可写入。
## Requirements
FR-001复用现有策略刷新全部项，无需重新解析；FR-002真实统计反馈并覆盖旧依据；FR-003折叠外按钮并改正证书过期统计口径；FR-004保留权限、版本保护与不变性；FR-005财务信用及横向排序证据不足仍须明确原因，不虚构数值。
FR-006 摘要必须绑定本次已保存的结果；POST响应读取前或POST到GET之间有其他刷新覆盖分值/依据时，拒绝旧摘要并提示重新核验。
FR-007 同项目重新加载生效评分项（含采纳后重载、重新打开抽屉）时，清除上次刷新摘要及无分值原因，避免旧统计混用于新规则。
## Key Entities
生效评分项、预判分值及依据、刷新摘要、未得分原因。
## Success Criteria
数值项（含0）+无数值项=处理总项；无证书刷新进入真实业务计算；折叠可操作；数据库/HTTP/UI一致；候选/阶段2不变。
## Assumptions
working_tree交付不自动提交推送部署；1117/1119生产验收必须在授权部署后执行，部署前仅保留复现证据。
