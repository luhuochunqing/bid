# AI标书核查语义与证据修复

## User Scenarios & Testing
- US1（P1）：完整保存法人、财务、信用、业绩、纳税社保和证书资格条件；证书匹配不能代表全部资格满足。
- US2（P1）：评分规则“不满足任意1项或未提供证明文件者，不得分”不能判成投标人负偏离；实际自述负偏离仍应拦截。缺失偏离表须先证明招标要求提供。
- US3（P1）：明确不要求CA/保证金时独立显示不适用，不计入通过数；适用性未知保持待确认。
- US4（P2）：证据显示原文件、文件内页与逻辑页，虚拟分页明确标识，历史缺失字段按未知处理。
## Functional Requirements
- FR001 完整资格条件与证书子集、附件要求分别表达。
- FR002 未逐项核验不得宣称全部资格满足。
- FR003 局部规则引用不产生负偏离，真实自述不能借规则免责。
- FR004 偏离表适用性由招标要求决定，未知不硬判缺失。
- FR005 不适用状态存取、汇总、展示一致，兼容历史报告。
- FR006 定位保留文件身份、文件内位置与分页来源。
## Key Entities
资格条件、证书要求、材料组成、核查结果、证据位置。
## Success Criteria
上述正反例全部通过行为测试；非证书资格零静默丢弃，不适用零计入通过；多册文件内位置逐页验证；虚拟页明确提示限制。
