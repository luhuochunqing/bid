# permission 模块

> 一旦我所属的文件夹有所变化，请更新我。

## 职责
提供系统权限相关的跨领域纯函数与策略类，聚焦权限键的过滤、归一化等无状态计算，供 `admin`、`auth` 等模块调用。

## 边界清单
| 文件 | 地位 | 功能 |
|------|------|------|
| `RoleProfileAdminPermissionFilter.java` | Policy | 过滤 OSS 用户不应持有的本地 admin 专属权限键，并提供权限列表规范化能力 |

## 当前边界
- 仅包含无状态静态方法，不依赖 Spring 上下文，便于单元测试与跨模块复用。
- 不持有业务状态，不参与持久化；仅作为权限计算的辅助策略。
