# 第三章 评标办法

本项目综合评分总分为 100 分。

| 序号 | 评分因素 | 评分规则 | 分值 |
| --- | --- | --- | --- |
| 1 | 财务状况及抗风险能力 | 审计意见连续3年无保留意见得10分。 | 10 |
| 2 | 运营能力及业绩 | 近三年内具有同类业绩最高得20分。 | 20 |
| 3 | 其余商务评分项 | 其余商务评分项合计得26分。 | 26 |
| 4 | 综合服务方案及技术响应 | 方案编制完整且技术响应完善得44分。 | 44 |
