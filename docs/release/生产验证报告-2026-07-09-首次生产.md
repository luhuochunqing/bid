- AI 健康检查通过（provider/model 配置存在）

## 10. 已知问题与风险

### 10.1 Sidecar 组件 DOWN（非阻断）

- **现象**：`http://localhost:8000` Connection refused
- **影响**：sidecar 功能不可用
- **降级**：`fallbackAvailable: true`，后端已有降级方案
- **处置**：如需 sidecar 功能，需单独部署 sidecar 服务
- **风险等级**：低

### 10.2 Kafka 事件集成待配置（非阻断）

- **现象**：Kafka SDK 启动时 `eventTopicConsumerMap is null`
- **影响**：组织事件集成不可用
- **处置**：需客户配置 Kafka topic 后重新验证
- **风险等级**：低（不影响核心 API 功能）

### 10.3 CRM Webhook 待首次触发

- **现象**：CRM webhook 配置已就绪，但未收到首次事件推送
- **影响**：CRM 数据变更实时同步功能待验证
- **处置**：需 CRM 团队触发一次测试事件
- **风险等级**：低

### 10.4 跨部门协作人员 403（已修复）

- **现象**：跨部门协同人员（bid-otherDept）访问首页 alerts/history 时返回 403
- **根因**：权限校验未覆盖 bid-otherDept 角色的 alerts/history 访问路径
- **修复**：PR !1969 已合并并部署到生产
- **验证**：修复后该角色正常访问
- **风险等级**：已消除

### 10.5 OSS 用户密码登录 401（预期行为）

- **现象**：17 次 401 Unauthorized + 32 条 ERROR 日志
- **原因**：OSS 同步用户无本地密码，尝试密码登录时 CRM POST form 返回 500
- **影响**：无（OSS 用户应走 SSO 登录）
- **处置**：无需修复，属于预期行为
- **风险等级**：无

### 10.6 AI API Key 未配置（需处理）

- **现象**：`aiProvider.details.apiKeyConfigured=false`（健康检查 JSON 实查）
- **影响**：AI 相关功能（标书生成、智能补全、文档洞察 AI 辅助等）调用时会因鉴权失败而不可用
- **根因**：生产环境 `backend.env` 未注入 deepseek API Key（或相关环境变量）
- **处置**：**需在试运行期前由开发团队或客户运维配置真实 API Key**，并在配置后复测 AI 功能
