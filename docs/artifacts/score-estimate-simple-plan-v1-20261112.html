先按满足比例
让预计得分可用

有则满分，无则零分，部分满足按比例。用于投标前粗估，最终评审另算。

预计得分 = 该项满分 × min(已满足数量 ÷ 要求数量, 1)

同一资料不重复计数；直接用数量比计算，只在最后保留两位小数。

第一版规则

  • 明确要求N项/个/份，就按N计算。
  • 数量不明确或有冲突，默认1，按有无粗估，并写清假设。
  • 过期、退役、重复资料不算已满足。
  • 资料查询成功但无记录，显示0分；查询失败明确报未计算。

本轮收掉的复杂度

  • 撤除“包含复杂关键词就整项禁算”。
  • 预计分不再套固定六区域15+5公式。
  • 不以严格证书全文语法作为粗估前提。
  • 复用现有资料库、比例计分、状态、刷新和保存链路。

实施顺序

  1. 先补全有、没有、部分、去重、精度测试，再补简单计分。
  2. 接入现有知识库取数，保留历史因素名兼容。
  3. 删除临时禁算分支，完成真实MySQL刷新和回读验证。
  4. 页面显示“知识库粗估”，保留资料来源与未核验条件。
  5. 清理后重新测试、构建及独立审查；旧测试结果不复用为新版通过。

项目1371的完成标准

运营能力及业绩、服务案例及业绩、品牌授权、仓储能力这四个已识别客观知识库项，在正常查询成功时均有数值（可为0）。具体数值按真实去重后的可用资料计算。

财务、纯主观或无资料源项目单独待评，不阻断其余项目。复杂排名、网点覆盖、承诺等只列为本次未核验条件，不假称正式评审已确认。

不新增规则平台、数据库表、HTTP接口或解析流程；实际评分不变。

当前已完成本地实现：182项后端测试、57项前端测试及构建通过，两路独立复审通过。尚未提交或部署，真实环境分值仍需授权发布后刷新验收。
