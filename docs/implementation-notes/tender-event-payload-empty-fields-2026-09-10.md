# 标讯事件空字段契约实施记录（2026-09-10）

## 客户确认

真实联调标讯 `tenderId=4173` 已通过 SDK 推送成功，但 `data` 仅出现三个有值字段：
`tenderId`、`externalId`、`title`。客户进一步明确：约定字段即使无值也必须传递空字符串，不能省略。

## 实现决策

- `TenderEventPayload` 的 20 字段范围保持不变。
- `tenderId` 继续使用数字类型且保持必填。
- 其余 19 个字符串、枚举标签及时间字段始终写入 `data`。
- `null` 与仅含空白字符的字符串统一序列化为 `""`。
- 有值的枚举继续转中文标签；有值的时间继续使用 `yyyy-MM-dd HH:mm`。
- 规则放在纯映射边界 `TenderEventPayloadMapper.toData`，流水留痕和 SDK 实际发送继续复用同一份 Map，避免字段形状漂移。

## 验证口径

以 `4173` 的三字段样本构造回归测试，断言 SDK 收到的 `eventContent` 解码后：

- 恰好包含全部 20 个约定字段；
- 三个已有字段保持原值；
- 其余 17 个字段存在且值均为 `""`。
