# 评分走立项招标文件

不在规格里、实现时定下来的选择：

- 立项 `TENDER` 优先于 Bid Agent `TENDER_FILE`，再兜底旧快照正文。客户不再经过「启动 AI 生成初稿」。
- 不新建快照表，不调 Bid Agent 导入。解析时现读立项文件再抽正文。
- OBS（`obs-direct:`）用已有签发器拿预签名 URL 再 GET 字节，避免再铺一条下载网关。
- 打开评分抽屉且没有评分项时自动 `POST /parse`。没有立项文件则提示「请先在立项阶段上传招标文件」。
- 编制页 / 流程卡上的初稿入口去掉。Bid Agent 后端先留着，不在这条产品路上。
