# 工作台待办模块角色化改造 - 验收清单

> 关联 spec：./spec.md
> 创建日期：2026-07-15

## 模块 1：任务·待办

- [ ] 所有角色登录，任务待办只显示标书制作阶段（DRAFTING）的任务
- [ ] 任务待办只显示当前用户为执行人（assigneeId）的任务
- [ ] 任务待办不显示已完成（COMPLETED）的任务
- [ ] 跨部门协同人员（bid-otherDept）点击任务待办 → 跳转 `/task-board`
- [ ] 其他角色点击任务待办 → 跳转项目详情标书制作阶段
- [ ] `GET /api/tasks/my?projectStage=DRAFTING` 返回正确过滤结果
- [ ] 不传 projectStage 参数时行为不变（向后兼容）

## 模块 2：标讯·待办

- [ ] 投标管理员登录，标讯待办显示待分配+已评估的标讯
- [ ] 投标组长登录，标讯待办显示待分配+已评估的标讯
- [ ] 投标系统管理员登录，标讯待办显示待分配+已评估的标讯
- [ ] 项目负责人登录，标讯待办显示跟踪中的标讯
- [ ] 投标专员登录，不显示标讯待办模块
- [ ] 跨部门协同人员登录，不显示标讯待办模块

## 模块 3：项目·待办

- [ ] 投标管理员登录，项目待办显示已立项 + 自己作为标书审核人的项目
- [ ] 投标组长登录，项目待办显示已立项 + 自己作为标书审核人的项目
- [ ] 投标专员登录，项目待办显示自己是投标负责人/辅助人员的项目（已结项的不显示）
- [ ] 项目负责人登录，项目待办显示待立项 + 标书审核人 + 待结项的项目

## 模块 4：资源·待办

- [ ] 资源待办显示待审批的账户借用申请
- [ ] 资源待办显示待审批的 CA 借用申请
- [ ] 两类申请合并展示，按时间排序
- [ ] 最多显示 4 条
- [ ] 无待审批数据时显示空状态
