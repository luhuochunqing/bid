**状态符号**：
- ✅ = 证据通过
- ❌ = 证据失败（必须修复）
- ⚠ = 有警告（需说明）
- ⊘ = 不适用/无此维度

**似然比参考**：
- ≈1.0 = 无诊断价值（test pass、门禁全绿）
- 3.0-5.0 = 中等诊断价值（架构测试、一致性扫描）
- 8.0+ = 强诊断价值（跨系统影响面分析、人类 code review）
- 15.0+ = 极强诊断价值（生产验证）

## 置信度计算

$$
P(\text{完成}|\text{证据}) = \frac{\prod LR_i \cdot P(\text{完成})}{\prod LR_i \cdot P(\text{完成}) + (1 - P(\text{完成}))}
$$

其中 $P(\text{完成})$ 为先验概率（基于历史 base rate），$LR_i$ 为各维度似然比。
