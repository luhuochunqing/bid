# Resource 模块

> 一旦我所属的文件夹有所变化，请更新我。

## 职责说明
资源模块负责账户等资源型业务页面。
该目录聚焦资源申请、查询、流转和归档，不承载基础组件实现。
子目录按资源类型继续拆分，保持页面边界清晰。

## 边界清单

| 文件 | 地位 | 功能 |
|------|------|------|
| `Account.vue` | View | 平台账户页 |
| `MarginManagement.vue` | View | 保证金管理页 |
| `CAManagement.vue` | View | CA 信息管理页 |
| `components/` | 目录 | 资源模块共享子组件 |
